mimiqcircuits.backends¶

Backend interface for quantum circuit simulators.

Subclass LocalBackend for a simulator that runs in this process, or RemoteBackend for one that runs on a service; MimiqRemoteBackend runs circuits on the MIMIQ cloud. See Implementing a Custom Backend for a step-by-step guide.

Where things live:

capabilities, limits, topology, admission  -> .capabilities
Backend, LocalBackend, RemoteBackend, State -> .backend
Fidelity types and reducers                 -> .fidelity
CompiledCircuit types, CompileMetadata      -> .compiled
AbstractPass, PassPipeline, apply_passes    -> .passes
CanonicalDecomposePass                      -> .concrete_passes
extract_projection, evaluate_projection     -> .measure_analysis
CompiledProjection                          -> .compiled_projection
StochasticKind and helpers                  -> .stochastic_kind
Progress, TqdmProgress, NoProgress          -> .progress
MimiqRemoteBackend                          -> .remote

Import the names from the package itself:

from mimiqcircuits.backends import Backend, LocalBackend, ...

class Fidelity[source]¶

Bases: object

Base class for typed fidelity values.

The subclasses say what a fidelity number means: ExactFidelity, UnknownFidelity, TruncationLowerBound, LowerBoundPerStep and EstimatedFidelity. as_lower_bound(), as_expected() and as_interval() reduce any of them to plain numbers.

Examples

>>> from mimiqcircuits import *
>>> from mimiqcircuits.backends import *

An MPS simulator that discarded 1% of the norm reports a lower bound, not an exact value.

>>> f = TruncationLowerBound(0.99)
>>> as_lower_bound(f), as_expected(f)
(0.99, 0.99)

An estimate with a standard error is reduced conservatively by as_lower_bound() (mean minus three standard errors).

>>> e = EstimatedFidelity(mean=0.9, stderr=0.01)
>>> round(as_lower_bound(e), 2), as_expected(e)
(0.87, 0.9)
>>> as_lower_bound(UnknownFidelity())
nan

class AbstractPass[source]¶

Bases: ABC

Base class for circuit-transformation passes.

To write a pass, subclass it and implement spec() and apply(). Override preserves() when the pass breaks a circuit feature.

Examples

A pass that removes every Barrier.

>>> from mimiqcircuits import *
>>> from mimiqcircuits.backends import (
...     AbstractPass, PassContext, PassResult, PassSpec)
>>> class DropBarriersPass(AbstractPass):
...     def spec(self):
...         return PassSpec("drop_barriers")
...     def apply(self, ctx, circuit):
...         kept = [i for i in circuit if not isinstance(i.operation, Barrier)]
...         # No qubit is relabelled, so the result reports nothing.
...         return Circuit(kept), PassResult()
>>> c = Circuit().push(GateH(), 0).push(Barrier(1), 0).push(GateX(), 0)

abstract execute(circuit, *, nsamples=1000, seed=None, rng=None, passes=None, fuse=None, canonicaldecompose=None, reorderqubits=None, remove_swaps=None, simplify=None, reorderqubits_seed=None, callback=None, param_grid=None, strict_pass_order=True)[source]¶

Run circuit on this backend and return its results.

To request specific amplitudes or expectation values, push Amplitude or ExpectationValue instructions into circuit and read them from results.zstates.

The preparation flags (fuse, canonicaldecompose, reorderqubits, remove_swaps, simplify) adjust the backend’s default_passes() instead of replacing them. Each speaks about one kind of pass: None leaves that pass as the backend declared it, False drops it, and any other value replaces it with the pass the backend builds for that flag, or adds that pass when the backend declared none of that kind. So fuse=False means “the backend’s pipeline, without fusion”. A pass that no flag names stays even when every flag is False.

The flags have a fixed order among themselves: remove swaps, simplify, canonical decompose, fuse, reorder. A pass added by a flag goes just before the first declared pass of a kind that runs later, or at the end if there is none. passes are appended after all of that, as given; nothing is deduplicated.

simplify=True rewrites the circuit with simplify_pass() while keeping its unitary exactly: inverse pairs cancel, rotations merge, and one- and two-qubit blocks are resynthesised with fewer gates.

Parameters:

  • circuit – A Circuit or a list of circuits. Local backends also take a SweepExperiment, which runs the circuit once per point of its table.

  • nsamples (int) – Number of shots.

  • seed (int | None) – Integer seed for all randomness of the run. Mutually exclusive with rng; with neither, the backend draws fresh entropy.

  • rng (Random | None) – A random.Random to draw the seed from. It is advanced, so two runs with the same generator differ.

  • passes (PassPipeline | None) – Extra passes to run after the backend’s adjusted pipeline.

  • fuse (bool | None) – Install (True) or drop (False) gate fusion.

  • canonicaldecompose (bool | None) – Install or drop the decomposition into the canonical gate set.

  • reorderqubits (bool | str | None) – Install or drop qubit reordering; a string names the reordering method.

  • remove_swaps (bool | None) – Install or drop SWAP removal.

  • simplify (bool | None) – Install or drop circuit simplification. Off unless set.

  • reorderqubits_seed (int | None) – Seed for the reordering pass. It configures reordering; it does not request it.

  • callback – Called by the backend during evolution, once per step.

  • param_grid (list[dict] | None) – A list of dictionaries, each mapping the circuit’s symbols (or their names) to values, such as [{theta: 0.1}, {theta: 0.2}]. Each dictionary is substituted into circuit with evaluate() and runs as its own execution, with a seed derived from seed or rng, so points are independent and a repeated sweep with the same seed gives the same results. Every dictionary must bind all free symbols. An empty list runs circuit once.

  • strict_pass_order (bool) – On a remote backend that does not declare "pass_order_honored", refuse a non-empty passes instead of submitting it as an unordered set.

Returns:

A QCSResults. A list of circuits gives a list of results in the same order; param_grid or a SweepExperiment gives one result per point (a list of such lists for a list of circuits).

Raises:

  • TypeError – If both seed and rng are given, or a flag has the wrong type (for example fuse=0).

  • NotImplementedError – If param_grid is given to a remote backend that does not support it (such as MimiqRemoteBackend), or a flag asks for a pass the backend cannot build.

  • RemotePassOrderError – See strict_pass_order.

class LocalBackend[source]¶

Bases: Backend

Base class for simulators that run in this process.

Subclasses implement build_state(), compile() and evolve(), plus the Backend identity members; they may override prepare_trajectory(), recompile_per_trajectory(), bind() and compile_progress(), and opt into the runtime-loss driver with uses_loss_driver(), apply_instruction(), sample_kraus() and apply_segment().

In return they inherit execute(), which runs the pass pipeline, splits the trailing measurements off into a classical projection, and then either evolves the circuit once and samples the final state, or evolves one fresh state per shot when the circuit has mid-circuit measurements, noise, or loss.

Examples

A backend for circuits of X and CX gates only. Its state is a single computational basis state, so it is exact and fully deterministic.

>>> from mimiqcircuits import *
>>> from mimiqcircuits.backends import (
...     DefaultCompiledCircuit, ExactFidelity, LocalBackend, State)

The state holds the three registers, and samples by returning its basis state nsamples times.

>>> class BasisState(State):
...     def __init__(self, nq, nb, nz):
...         self.qubits = [0] * nq
...         self.bits = [0] * nb
...         self.zvars = [0j] * nz
...     @property
...     def num_qubits(self):
...         return len(self.qubits)
...     @property
...     def num_bits(self):
...         return len(self.bits)
...     @property
...     def num_zvars(self):
...         return len(self.zvars)
...     @property
...     def classical_bits(self):
...         return BitString(self.bits)
...     @property
...     def complex_values(self):
...         return list(self.zvars)
...     def amplitude(self, bs):
...         return 1.0 + 0j if list(bs) == self.qubits else 0j
...     def sample(self, nsamples, rng=None):
...         return [BitString(self.qubits) for _ in range(nsamples)]

The backend declares what it supports, builds states, and evolves them. compile has nothing to lower here, so it wraps the circuit as it is.

>>> class BasisBackend(LocalBackend):
...     @property
...     def name(self):
...         return "Basis"
...     @property
...     def version(self):
...         return "0.1"
...     def capabilities(self):
...         return {"sampling", "classical_bits", "midcircuit_measure"}
...     def build_state(self, nq, nb=0, nz=0, **kwargs):
...         return BasisState(nq, nb, nz)
...     def compile(self, circuit):
...         return DefaultCompiledCircuit(circuit)
...     def evolve(self, state, compiled, *, rng=None, callback=None,
...                stopped=None):
...         for inst in compiled.source:
...             op, qs = inst.operation, inst.qubits
...             if isinstance(op, GateX):
...                 state.qubits[qs[0]] ^= 1
...             elif isinstance(op, GateCX):
...                 state.qubits[qs[1]] ^= state.qubits[qs[0]]
...             elif isinstance(op, Measure):
...                 state.bits[inst.bits[0]] = state.qubits[qs[0]]
...             else:
...                 raise ValueError(f"unsupported operation {op}")
...         return state, ExactFidelity()

execute does the rest. The final measurements never reach evolve: the driver samples the state and maps the samples to the classical register itself.

>>> backend = BasisBackend()
>>> c = Circuit()
>>> c.push(GateX(), 0)
1-qubit circuit with 1 instruction:
└── X @ q[0]

>>> c.push(GateCX(), 0, 1)
2-qubit circuit with 2 instructions:
├── X @ q[0]
└── CX @ q[0], q[1]

>>> c.push(Measure(), range(2), range(2))
2-qubit, 2-bit circuit with 4 instructions:
├── X @ q[0]
├── CX @ q[0], q[1]
├── M @ q[0], c[0]
└── M @ q[1], c[1]

>>> res = backend.execute(c, nsamples=3, seed=1)
>>> res.cstates
[bs"11", bs"11", bs"11"]
>>> res.fidelities
[1.0]

The default can_handle() rejects what the backend does not declare, such as noise.

>>> noisy = Circuit().push(Depolarizing(1, 0.1), 0)
>>> backend.can_handle(noisy)
Inadmissible(reason="circuit contains a noise channel but backend Basis does not declare the 'noise' capability")

optimize(experiment, initparams=None, *, return_history=False, **kwargs)[source]¶

Minimize a cost read from a parametric circuit by running it on this backend.

At every step the optimizer proposes values for the circuit’s symbols, the circuit is evaluated with them and run with execute(), and the cost is the real part of the mean of z-register zregister over the samples. Push the quantity to minimize into that register, for example with push_expval().

Call it with an OptimizationExperiment, a list of them, or a circuit and a dictionary of initial values for all its symbols plus the experiment’s fields as keywords:

  • optimizer: "BFGS", "LBFGS", "CG", "NELDERMEAD", "NEWTON", "COBYLA" (default) or "CMAES". All but "CMAES" come from scipy.optimize.minimize(); "CMAES" needs the cmaes extra (pip install 'mimiqcircuits[cmaes]').

  • maxiters: iteration limit, or None for the optimizer’s own.

  • zregister: index of the z-register holding the cost (default 0).

  • label: a name for the experiment.

With an experiment these fields come from it, and passing them again is an error. Every other keyword goes to execute() on each evaluation: nsamples, seed, fuse, passes and so on. With a fixed seed every evaluation draws the same random numbers, so a noisy cost does not jump between otherwise equal points.

Parameters:

  • experiment – An OptimizationExperiment, a list of them, or a symbolic circuit.

  • initparams – Initial values when experiment is a circuit; must be None otherwise.

  • return_history – Also keep every evaluated run.

  • **kwargs – Experiment fields (with a circuit only) and execute() options.

Returns:

An OptimizationResults with the lowest-cost OptimizationRun and, with return_history=True, every evaluated run in order. A list of experiments gives a list of results in the same order.

Raises:

  • ValueError – For an unknown optimizer, a zregister the circuit does not have, or a circuit and initial values that do not form a valid experiment.

  • TypeError – If initparams or an experiment field is given together with an experiment.

Examples

A one-qubit backend for circuits of RY gates followed by ⟨Z⟩ measurements. It tracks the rotation angle and writes cos(theta) to the z-register.

>>> from mimiqcircuits import *
>>> from mimiqcircuits.backends import (
...     DefaultCompiledCircuit, LocalBackend, State)
>>> import math
>>> from symengine import symbols
>>> class RYState(State):
...     num_qubits = property(lambda self: 1)
...     num_bits = property(lambda self: 0)
...     num_zvars = property(lambda self: len(self.z))
...     classical_bits = property(lambda self: BitString(0))
...     complex_values = property(lambda self: list(self.z))
...     def __init__(self, nz):
...         self.theta, self.z = 0.0, [0j] * nz
...     def amplitude(self, bs):
...         raise NotImplementedError
...     def sample(self, nsamples, rng=None):
...         return [BitString(1)] * nsamples
>>> class RYBackend(LocalBackend):
...     name = "RY"
...     version = "0.1"
...     def capabilities(self):
...         return {"zvars", "expectation_1q"}
...     def build_state(self, nq, nb=0, nz=0, **kwargs):
...         return RYState(nz)
...     def compile(self, circuit):
...         return DefaultCompiledCircuit(circuit)
...     def evolve(self, state, compiled, *, rng=None,
...                callback=None, stopped=None):
...         for inst in compiled.source:
...             if isinstance(inst.operation, GateRY):
...                 state.theta += float(inst.operation.theta)
...             else:
...                 state.z[inst.zvars[0]] = math.cos(state.theta)
...         return state, 1.0

The cost is ⟨Z⟩ on qubit 0, written to z-register 0. It is lowest, -1, at theta = pi.

├── RY(theta) @ q[0]
└── ⟨Z⟩ @ q[0], z[0]

Backend that runs circuits on the MIMIQ cloud service.

The simulator algorithm is fixed at construction; the other server options (bonddim, entdim, mpscutoff, mpsmethod, mpotraversal, timelimit, noisemodel) are given to execute() or submit().

  1. The capabilities are decided on the client, since the service does not report them: a fixed set, plus "bond_dim" and "schmidt_rank" when algorithm is "auto" or "mps".

  2. "pass_order_honored" is not declared, because the service takes a flat set of options (remove_swaps, fuse, …), not an ordered pipeline. extract_projection(circuit)[source]¶

Split circuit into the part to evolve and a classical projection.

The circuit is scanned backwards. Trailing operations that do not change the final quantum state seen by the remaining operations move into a projection circuit of classical-bit instructions; the rest is the quantum circuit the simulator evolves.

Absorbed operations:

  • Trailing Measure(q, b) / MeasureReset(q, b) → Measure(q, b).

  • Trailing classical logic: Not, And, Or, Xor, SetBit0, SetBit1. These read other classical bits, so what comes out is a straight-line program over the register rather than a per-bit map, emitted in source order. A logic op is absorbed only when no operation left in quantum_circuit touches any of its bits, otherwise moving it past that operation would change what it reads.

  • Trailing GateID — dropped as a no-op. GateX / GateY / GateZ are NOT absorbed: Y and Z carry phases that would corrupt amplitude lookups, and X absorbed alone would require XOR-ing the qubit-flip pattern into every user-supplied bitstrings entry for amplitudes to stay consistent. Keeping all Paulis in quantum_circuit means the projection only contains phase-free transformations and amplitude lookups need no compensation.

  • Reset(q) whose qubit has captured pending bits → those bits become classical constants (SetBit0 / SetBit1 based on absorbed X parity). A Reset whose qubit has no captured bits is harmless and dropped.

Anything that cannot be absorbed (other gates, Kraus channels, IfStatement, Amplitude, ExpectationValue, …) blocks its qubits and survives into quantum_circuit.

If the source has no classical register, the projection is synthesised over an identity bit↔qubit mapping (bit i mirrors qubit i, length = circuit.num_qubits()).

A write to a classical bit that a later absorbed operation overwrites without reading is dropped from the projection, so reusing a classical bit does not cost a per-shot write that nothing observes.

class StochasticKind(value, names=<not given>, *values, module=None, qualname=None, type=None, start=1, boundary=None)[source]¶

Bases: IntEnum

When a backend resolves the randomness of an operation.

The members are ordered, Deterministic < TrajectorySampleable < RuntimeOnly, so max gives the kind of a group of operations.

  • Deterministic: no randomness; LocalBackend.compile() can lower the operation from the circuit alone.

  • TrajectorySampleable: random, but resolvable in LocalBackend.prepare_trajectory() from random draws alone, because the outcomes and their probabilities do not depend on the state, for this backend.

  • RuntimeOnly: must be resolved during LocalBackend.evolve(), because the probabilities or a control-flow condition depend on the live quantum or classical state.

The kind of an operation depends on the backend; see Backend.stochastic_kind().

default_stochastic_kind(op)[source]¶

Classify an operation without reference to a backend.

This is the default of Backend.stochastic_kind(). Backends that classify an operation differently override that method, not this function.

  • IfStatement: the kind of the operation it wraps.

  • Kraus channels: TrajectorySampleable if mixed-unitary, otherwise RuntimeOnly.

  • Loss and every measurement: RuntimeOnly.

  • Everything else: Deterministic.

Parameters:

op – An operation, or an instruction whose operation is classified.

Returns:

A StochasticKind.

Return type:

StochasticKind

>>> from mimiqcircuits import *
>>> from mimiqcircuits.backends import default_stochastic_kind
