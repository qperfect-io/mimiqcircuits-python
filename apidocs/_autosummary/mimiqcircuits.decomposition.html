mimiqcircuits.decomposition¶

Quantum circuit decomposition framework.

This module provides a flexible framework for decomposing quantum circuits into different target gate sets.

Core Concepts¶

RewriteRule: Single-step transformation rules that define how to transform operations, but not when to stop.

DecompositionBasis: Recursive decomposition targets that define both what is terminal (operations that shouldn’t be decomposed) and how to decompose non-terminal operations.

Main Functions¶

  • decompose(): Recursively decompose a circuit to a target basis

  • decompose_step(): Apply a single decomposition step

Available Bases¶

  • CanonicalBasis: Decomposes to GateU + GateCX (default)

  • CliffordTBasis: Decomposes to Clifford+T gate set

  • FlattenedBasis: Flattens GateCall/Block containers

  • QASMBasis: Decomposes to OpenQASM 2.0 gate set

  • StimBasis: Decomposes to Stim Clifford gate set

  • RuleBasis: Wraps any RewriteRule as a DecompositionBasis

Available Rules¶

  • CanonicalRewrite: Uses built-in gate decomposition methods

  • FlattenContainers: Flattens GateCall/Block containers

  • ZYZRewrite: ZYZ Euler angle decomposition

  • SpecialAngleRewrite: Rotations with special angles -> Clifford+T

  • ToZRotationRewrite: Convert RX/RY to RZ + Clifford

  • ToffoliToCliffordTRewrite: Toffoli -> Clifford+T decomposition

  • SolovayKitaevRewrite: Solovay-Kitaev approximation with Clifford+T

  • GridSynthRewrite: Ross-Selinger approximation of RZ with Clifford+T

Usage¶

Basic decomposition to canonical basis (GateU + GateCX):

>>> from mimiqcircuits import Circuit, GateH, GateCCX
>>> from mimiqcircuits.decomposition import decompose
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateCCX(), 0, 1, 2)
3-qubit circuit with 2 instructions:
├── H @ q[0]
└── C₂X @ q[0:1], q[2]

>>> decomposed = decompose(c)

Decompose to Clifford+T:

>>> from mimiqcircuits.decomposition import decompose, CliffordTBasis
>>> decomposed = decompose(c, CliffordTBasis())

Use a specific rewrite rule:

>>> from mimiqcircuits.decomposition import decompose_step, ZYZRewrite
>>> stepped = decompose_step(c, ZYZRewrite())

Creating Custom Rules¶

You can create custom rewrite rules by subclassing RewriteRule:

>>> from mimiqcircuits.decomposition import RewriteRule
>>> class MyRewrite(RewriteRule):
...     def matches(self, op):
...         return isinstance(op, SomeGate)
...
...     def decompose_step(self, op, qubits, bits, zvars):
...         from mimiqcircuits import Circuit
...         circ = Circuit()
...         # ... decomposition logic ...
...         return circ

And custom decomposition bases by subclassing DecompositionBasis:

>>> from mimiqcircuits.decomposition import DecompositionBasis
>>> class MyBasis(DecompositionBasis):
...     def isterminal(self, op):
...         return isinstance(op, (TargetGate1, TargetGate2))
...
...     def decompose(self, op, qubits, bits, zvars):
...         # Use a rewrite rule or custom logic
...         return SomeRewrite().decompose_step(op, qubits, bits, zvars)
class mimiqcircuits.decomposition.RewriteRule[source]¶

Bases: ABC

Abstract base class for single-step rewrite rules.

A RewriteRule defines how to transform an operation into a sequence of simpler operations, but not when to stop. For recursive decomposition to a target set of operations, see DecompositionBasis.

Subclasses must implement:

  • matches(): Return True if this rule can transform the operation

  • decompose_step(): Apply the transformation

Example

>>> class MyRewrite(RewriteRule):
...     def matches(self, op: Operation) -> bool:
...         return isinstance(op, GateToffoli)
...
...     def decompose_step(self, op, qubits, bits, zvars):
...         from mimiqcircuits import Circuit
...         circ = Circuit()
...         # ... decomposition logic ...
...         return circ

class mimiqcircuits.decomposition.DecompositionBasis[source]¶

Bases: ABC

Abstract base class for decomposition targets.

A DecompositionBasis combines two concerns:

  1. What is terminal: Operations that should not be decomposed further.

  2. How to decompose: The transformation logic for non-terminal operations.

Subclasses must implement:

  • isterminal(): Return True if the operation is in the target set

  • decompose(): Decompose non-terminal operations

Example

>>> class CliffordT(DecompositionBasis):
...     def isterminal(self, op: Operation) -> bool:
...         return isinstance(op, (GateH, GateS, GateT, GateCX))
...
...     def decompose(self, op, qubits, bits, zvars):
...         # Use a rewrite rule to decompose
...         return CanonicalRewrite().decompose_step(op, qubits, bits, zvars)

class mimiqcircuits.decomposition.CanonicalBasis[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the canonical primitive gate set.

The canonical basis decomposes all operations to a minimal set of primitives:

  • GateU: Arbitrary single-qubit unitary

  • GateCX: Two-qubit CNOT gate

  • Measure, Reset: Measurement and reset operations

  • Barrier: Scheduling barriers

  • Classical operations, annotations, noise channels

This is the default basis used by decompose().

Example

>>> from mimiqcircuits import Circuit, GateH, GateCCX
>>> from mimiqcircuits.decomposition import decompose, CanonicalBasis
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateCCX(), 0, 1, 2)
3-qubit circuit with 2 instructions:
├── H @ q[0]
└── C₂X @ q[0:1], q[2]

>>> decomposed = decompose(c, CanonicalBasis())
>>> # All gates are now GateU or GateCX

class mimiqcircuits.decomposition.CliffordTBasis(sk_depth=None, rotations=None)[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the Clifford+T gate set.

Clifford+T is the standard universal gate set of error-corrected quantum computing. The terminal operations of this basis are those of StimBasis plus GateT and GateTDG, so the two bases always keep the same Clifford and stabilizer operations:

  • single-qubit Cliffords: GateID, GateX, GateY, GateZ, GateH, GateHXY, GateHYZ, GateS, GateSDG, GateSX, GateSXDG, GateSY, GateSYDG;

  • two-qubit Cliffords: GateCX, GateCY, GateCZ, GateSWAP, GateISWAP, GateISWAPDG, GateDCX, GateECR;

  • Pauli rotations by +-pi/2: GateRXX, GateRYY, GateRZZ, and RPauli with a non-identity Pauli string;

  • the non-Clifford GateT and GateTDG;

  • measurements, resets and measure-and-resets in the X, Y and Z bases, MeasureXX, MeasureYY, MeasureZZ and MeasurePauli;

  • Pauli noise: PauliX, PauliY, PauliZ, Depolarizing1, Depolarizing2 and PauliNoise;

  • barriers and annotations;

  • classical operations, which StimBasis does not keep;

  • an IfStatement whose body is terminal in this basis, with any condition. StimBasis only keeps a conditional GateX, GateY or GateZ on a single bit.

Non-terminal operations are rewritten by the first rule that matches, in this order:

  1. SpecialAngleRewrite: rotations by multiples of pi/4 to exact Clifford+T.

  2. ToffoliToCliffordTRewrite: GateCCX to Clifford+T with 7 T gates.

  3. A GateU whose angles are all zero (a pure global phase) is dropped.

  4. ZYZRewrite: GateU to RZ*RY*RZ.

  5. ToZRotationRewrite: GateRX, GateRY to GateRZ and Cliffords.

  6. The rotations rule (default GridSynthRewrite): remaining GateRZ to an approximate Clifford+T sequence.

  7. CanonicalRewrite: any other operation, toward GateU and GateCX.

The rotations rule only sees angles that step 1 could not decompose exactly. The body of an IfStatement goes through the same pipeline and stays conditional. No T-count optimization is performed on the result.

Parameters:

  • sk_depth (int | None) – Use SolovayKitaevRewrite with this recursion depth as the rotations rule.

  • rotations (RewriteRule) – Rule that synthesizes the remaining Z-rotations. The default GridSynthRewrite() approximates each rotation to operator-norm error 1e-10. The rule must match GateRZ with a numeric angle and emit only gates of this basis.

Raises:

ValueError – If both sk_depth and rotations are given, or if rotations does not match GateRZ.

Decomposing an operation that no rule handles, such as a noise channel other than the Pauli ones above, raises a DecompositionError.

Example

>>> from mimiqcircuits import Circuit, GateH, GateT, GateRZ
>>> from mimiqcircuits.decomposition import decompose, CliffordTBasis
>>> from mimiqcircuits.decomposition import GridSynthRewrite
>>> from symengine import pi
>>> c = Circuit()
>>> c.push(GateRZ(pi/4), 0)  # special angle, decomposed exactly
1-qubit circuit with 1 instruction:
└── RZ((1/4)*pi) @ q[0]

>>> decomposed = decompose(c, CliffordTBasis())

>>> # An arbitrary angle is approximated to 1e-10 by gridsynth
>>> c2 = Circuit()
>>> c2.push(GateRZ(0.123), 0)
1-qubit circuit with 1 instruction:
└── RZ(0.123) @ q[0]

>>> decomposed2 = decompose(c2, CliffordTBasis())

>>> # A looser error bound per rotation gives fewer T gates
>>> basis = CliffordTBasis(rotations=GridSynthRewrite(epsilon=1e-6))
>>> decomposed3 = decompose(c2, basis)

>>> # Solovay-Kitaev instead of gridsynth
>>> decomposed4 = decompose(c2, CliffordTBasis(sk_depth=0))

class mimiqcircuits.decomposition.QASMBasis[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the OpenQASM 2.0 gate library.

The terminal gates are the OpenQASM 2.0 built-ins and the gates of the qelib1.inc include file that have a direct MIMIQ counterpart, so a decomposed circuit can be written as OpenQASM 2.0 and read back by any parser that ships the standard qelib1.inc.

Terminal Operations¶

Fundamental gates (OpenQASM 2.0 built-in):

  • GateU, GateCX

Single-qubit gates from qelib1.inc:

  • Legacy U gates: GateU3, GateU2, GateU1

  • Pauli: GateID, GateX, GateY, GateZ

  • Hadamard: GateH

  • Phase: GateS, GateSDG, GateT, GateTDG

  • Rotations: GateRX, GateRY, GateRZ

Two-qubit gates from qelib1.inc:

  • Controlled Paulis and Hadamard: GateCY, GateCZ, GateCH

  • Controlled rotations: GateCRX, GateCRY, GateCRZ

  • GateSWAP

  • Ising couplings: GateRXX, GateRZZ

Three- and four-qubit gates from qelib1.inc:

  • GateCCX, GateCSWAP, GateC3X

Non-unitary operations:

  • Measure, Reset, Barrier

  • IfStatement whose inner operation is terminal

Custom gates:

  • GateCall whose declaration contains only terminal operations

Every other operation is decomposed through CanonicalRewrite. Operations that OpenQASM 2.0 cannot express and that have no decomposition into the gates above (noise channels, classical operations, annotations, Z-register operations, …) raise DecompositionError.

MeasureReset decomposes into Measure followed by Reset. This leaves the same state and bit as its canonical decomposition, a measurement and an X conditioned on its outcome, and unlike that conditional it can be written for a circuit of any number of bits. OpenQASM 2.0 has no loops, so WhileStatement raises DecompositionError.

Example

>>> from mimiqcircuits import Circuit, GateH, GateCCX
>>> from mimiqcircuits.decomposition import decompose, QASMBasis
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateCCX(), 0, 1, 2)
3-qubit circuit with 2 instructions:
├── H @ q[0]
└── C₂X @ q[0:1], q[2]

>>> # Decompose to QASM-compatible gates
>>> qasm_circuit = decompose(c, QASMBasis())

See also

CanonicalBasis, CliffordTBasis, StimBasis

class mimiqcircuits.decomposition.StimBasis[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the Stim stabilizer simulator gate set.

Stim is a high-performance stabilizer circuit simulator by Craig Gidney. It supports only Clifford gates, stabilizer operations, noise channels, and quantum error correction annotations.

Decomposition Pipeline¶

The decomposition follows this priority order:

  1. A GateU whose angles are all zero (a pure global phase) is dropped.

  2. ZYZRewrite: GateU -> RZ * RY * RZ

  3. SpecialAngleRewrite (Clifford-only): Rotations at k*pi/2 -> Clifford gates

  4. CanonicalRewrite: Fallback for other gates

Non-Clifford rotations (angles not multiples of pi/2) will raise a DecompositionError.

Terminal Operations¶

Single-qubit Clifford gates:

  • GateID

  • Pauli: GateX, GateY, GateZ

  • Hadamard: GateH, GateHXY, GateHYZ

  • Phase gates: GateS, GateSDG

  • Square root gates: GateSX, GateSXDG, GateSY, GateSYDG

Two-qubit Clifford gates:

  • Controlled Pauli: GateCX, GateCY, GateCZ

  • Swap family: GateSWAP, GateISWAP, ISWAP†

  • GateDCX, GateECR

Pauli rotations by +-pi/2:

  • GateRXX, GateRYY, GateRZZ with angle +-pi/2

  • RPauli with angle +-pi/2 and a non-identity Pauli string

Angles are compared modulo 2*pi, since a rotation by 3*pi/2 equals a rotation by -pi/2 up to a global phase. Other angles are decomposed.

Feedback:

  • IfStatement of GateX, GateY or GateZ conditioned on a single bit being 1. The same gate conditioned on the bit being 0 is decomposed into the gate followed by the gate conditioned on 1. Any other conditional operation has its body decomposed while staying conditional, and raises a DecompositionError if that does not lead to a conditional Pauli.

Measurements (all Pauli bases):

  • Measure, MeasureX, MeasureY

  • Two-qubit parities: MeasureXX, MeasureYY, MeasureZZ

  • Pauli products: MeasurePauli

Resets (all Pauli bases):

  • Reset, ResetX, ResetY

Measure-and-reset (all Pauli bases):

  • MeasureReset, MeasureResetX, MeasureResetY

Noise channels:

  • PauliX, PauliY, PauliZ

  • Depolarizing1, Depolarizing2

  • PauliNoise

QEC annotations:

  • Detector, ObservableInclude, QubitCoordinates

  • Barrier

class mimiqcircuits.decomposition.CanonicalRewrite[source]¶

Bases: RewriteRule

Rewrite rule that decomposes operations using their built-in decomposition.

This rule delegates to each operation’s _decompose method, which typically reduces gates to a minimal set of primitives (GateU, GateCX, etc.).

The canonical decomposition is the default decomposition defined by each gate class. Most gates decompose down to GateU (arbitrary single-qubit) and GateCX (two-qubit entangling gate).

Example

>>> from mimiqcircuits import GateH
>>> from mimiqcircuits.decomposition import CanonicalRewrite
>>> rule = CanonicalRewrite()
>>> rule.matches(GateH())
True
>>> circ = rule.decompose_step(GateH(), [0], [], [])
>>> print(circ)
1-qubit circuit with 1 instruction:
└── U((1/2)*pi, 0, pi, 0.0) @ q[0]

class mimiqcircuits.decomposition.ZYZRewrite[source]¶

Bases: RewriteRule

Rewrite rule for ZYZ Euler angle decomposition.

Decomposes single-qubit unitaries into the ZYZ Euler angle form: RZ(phi) * RY(theta) * RZ(lambda)

This is a standard decomposition for arbitrary single-qubit gates, producing only Z and Y rotations (plus a global phase for GateU).

class mimiqcircuits.decomposition.SolovayKitaevRewrite(depth=3, simplify=True, net_max_depth=10, net_max_points=50000, net_min_dist=0.02)[source]¶

Bases: RewriteRule

Rewrite rule using the Solovay-Kitaev algorithm.

Approximates arbitrary single-qubit unitaries using a sequence of Clifford+T gates. The algorithm recursively refines an initial approximation using group commutators, achieving ε-approximation with O(log^c(1/ε)) gates.

Parameters:

  • depth (int) – Recursion depth (default: 3). Higher = better precision, more gates.

  • simplify (bool) – Whether to simplify the resulting sequence (default: True).

  • net_max_depth (int) – Maximum depth for epsilon-net generation (default: 15).

  • net_max_points (int) – Maximum points in epsilon-net (default: 100,000).

  • net_min_dist (float) – Minimum distance between epsilon-net points (default: 0.01).

Supported operations:

  • GateRZ(λ): Z-rotation by angle λ

  • GateRY(θ): Y-rotation by angle θ

  • GateRX(θ): X-rotation by angle θ

  • GateU(θ, φ, λ, γ): General single-qubit unitary

Symbolic parameters are NOT supported.

Example

>>> from mimiqcircuits import GateRZ
>>> from mimiqcircuits.decomposition import SolovayKitaevRewrite
>>> rule = SolovayKitaevRewrite(depth=0)
>>> circ = rule.decompose_step(GateRZ(0.123), [0], [], [])

Note

The first call may be slow due to epsilon-net generation. Subsequent calls reuse the cached net.

class mimiqcircuits.decomposition.GridSynthRewrite(epsilon=1e-10, seed=0)[source]¶

Bases: RewriteRule

Rewrite rule that approximates GateRZ with a Clifford+T sequence, using the Ross–Selinger gridsynth algorithm.

For GateRZ(λ) the rule emits a sequence of GateH, GateS, GateSDG, GateZ, GateT and GateX whose unitary V satisfies min_φ ‖RZ(λ) − e^{iφ}V‖ ≤ epsilon in operator norm. The approximation holds up to a global phase, which is dropped. The T-count is about 3·log₂(1/epsilon) and, except for rare failures of the integer factoring step, optimal among ancilla-free Clifford+T circuits with this error. Angles that are multiples of π/4 give their exact short decomposition.

The factoring step is randomized. For a fixed seed, the same angle and tolerance always give the same sequence. Results are cached per angle, since circuits often repeat the same rotation.

The synthesis runs in the compiled mimiqcircuits._core extension without holding the GIL, so several threads can synthesize in parallel.

Parameters:

  • epsilon (float) – Operator-norm tolerance, 1e-100 <= epsilon < 1 (default 1e-10). A rotation takes a few milliseconds at 1e-10 and up to about a second at 1e-100.

  • seed (int) – Seed of the randomized factoring step, an integer in [0, 2**64) (default 0).

Raises:

  • ValueError – If epsilon or seed is out of range.

  • TypeError – If epsilon is not a real number or seed is not an integer.

Supported operations:

  • GateRZ(λ) with a numeric angle λ.

Symbolic angles are not matched. GateRX, GateRY and GateU must first be reduced to Z-rotations, for example with ZYZRewrite and ToZRotationRewrite. CliffordTBasis does this and uses this rule by default.

Example

>>> from mimiqcircuits import GateRZ, GateT
>>> from mimiqcircuits.decomposition import GridSynthRewrite
>>> def tcount(c):
...     return sum(isinstance(i.operation, GateT) for i in c)
>>> # Approximate one rotation to the default tolerance 1e-10
>>> circ = GridSynthRewrite().decompose_step(GateRZ(0.123), [0], [], [])
>>> # A coarser tolerance gives fewer T gates
>>> coarse = GridSynthRewrite(epsilon=1e-4).decompose_step(GateRZ(0.123), [0], [], [])
>>> tcount(coarse) < tcount(circ)
True

References

N. J. Ross and P. Selinger, “Optimal ancilla-free Clifford+T approximation of z-rotations”, Quantum Inf. Comput. 16, 901 (2016), arXiv:1403.2975.

mimiqcircuits.decomposition.decompose(source, basis=None, wrap=False)[source]¶

Recursively decompose a circuit to a target basis.

Decomposes all operations in the source until they are terminal in the given basis. This is the main entry point for circuit decomposition.

Parameters:

  • source (Circuit | Instruction | Operation) – The circuit, instruction, or operation to decompose.

  • basis (DecompositionBasis | RewriteRule | None) – The target decomposition basis. If a RewriteRule is provided, it is wrapped in a RuleBasis. Defaults to CanonicalBasis.

  • wrap (bool) – If True, wrap non-terminal ops instead of flattening them into primitives. Gates become a GateCall to a GateDecl, shared between identical gates. Other operations, such as MeasureReset or MeasurePauli, become a Block holding their decomposition, whose gates are wrapped in turn. This produces a circuit with only terminal ops, GateCalls and Blocks.

Returns:

A new Circuit containing only terminal operations (and GateCalls and Blocks if wrap=True).

Return type:

Circuit

>>> from mimiqcircuits import *
>>> from mimiqcircuits.decomposition import decompose, CanonicalBasis

├── H @ q[0]

>>> decomposed = decompose(c)
