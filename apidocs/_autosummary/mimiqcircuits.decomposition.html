mimiqcircuits.decomposition¶

Rewrite circuits into a target gate set.

The framework has two building blocks. A RewriteRule says how to rewrite one operation into simpler ones, one step at a time, and nothing about when to stop. A DecompositionBasis says what is terminal, the operations to keep, and how to rewrite everything else; decompose() applies it recursively until only terminal operations are left.

Functions

  • decompose(): recursively decompose a circuit, instruction or operation to a basis, and return a new circuit.

  • eachdecomposed(): the same, as a lazy iterator over the resulting instructions.

  • decompose_step(): apply a rewrite rule once, without recursion.

  • DecomposeIterator: the iterator behind decompose() and eachdecomposed().

A function that takes a basis also accepts a rewrite rule, wrapped in a RuleBasis.

Bases

  • CanonicalBasis: GateU and GateCX, plus the non-unitary primitives. The default.

  • CliffordTBasis: Clifford+T, approximating arbitrary rotations.

  • StimBasis: the Clifford gates, measurements and noise of Stim.

  • QASMBasis: the OpenQASM 2.0 gate library (qelib1.inc).

  • FlattenedBasis: expands GateCall, Block and BlockCall containers and keeps everything else.

  • RuleBasis: applies one rewrite rule until it no longer matches.

Rules

  • CanonicalRewrite: the built-in decomposition of each operation.

  • FlattenContainers: expands one level of GateCall, Block and BlockCall.

  • ZYZRewrite: GateU and GateRX to Z and Y rotations.

  • ToZRotationRewrite: GateRX and GateRY to GateRZ and Clifford gates.

  • SpecialAngleRewrite: rotations by multiples of pi/4 to exact Clifford+T gates.

  • ToffoliToCliffordTRewrite: GateCCX to Clifford+T with 7 T gates.

  • GridSynthRewrite: GateRZ approximated with Clifford+T by the Ross-Selinger algorithm.

  • SolovayKitaevRewrite: single-qubit rotations approximated with Clifford+T by the Solovay-Kitaev algorithm.

An operation that a basis cannot rewrite raises DecompositionError.

Examples

>>> from mimiqcircuits import *
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateCCX(), 0, 1, 2)
3-qubit circuit with 2 instructions:
├── H @ q[0]
└── C₂X @ q[0:1], q[2]

>>> # the default basis leaves only GateU and GateCX
>>> sorted({type(inst.operation).__name__ for inst in decompose(c)})
['GateCX', 'GateU']

>>> # the Clifford+T basis rewrites the Toffoli with H, T, T† and CX
>>> sorted({type(inst.operation).__name__ for inst in decompose(c, CliffordTBasis())})
['GateCX', 'GateH', 'GateT', 'GateTDG']

>>> # a rule applied once rewrites the Toffoli into 15 gates and keeps H
>>> stepped = decompose_step(c, ToffoliToCliffordTRewrite())
>>> len(stepped), stepped[0].operation
(16, H)

To add a gate set of your own, subclass RewriteRule or DecompositionBasis; their documentation shows how.

class RewriteRule[source]¶

Bases: ABC

Abstract base class for single-step rewrite rules.

A rewrite rule says how to rewrite an operation into a circuit of other operations, but not when to stop. Apply it once with decompose_step(), or repeatedly with decompose(), which wraps it in a RuleBasis and rewrites until nothing matches. For a target gate set, see DecompositionBasis.

A subclass implements matches() and decompose_step().

Examples

>>> from mimiqcircuits import *
>>> # a rule that rewrites a SWAP into three CX gates
>>> class SwapToCX(RewriteRule):
...     def matches(self, op):
...         return isinstance(op, GateSWAP)
...
...     def decompose_step(self, op, qubits, bits, zvars):
...         # qubits are the targets of the SWAP in the circuit
...         a, b = qubits
...         circ = Circuit()
...         circ.push(GateCX(), a, b)
...         circ.push(GateCX(), b, a)
...         circ.push(GateCX(), a, b)
...         return circ
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateSWAP(), 0, 1)
2-qubit circuit with 2 instructions:
├── H @ q[0]
└── SWAP @ q[0:1]

>>> # the SWAP matches and is rewritten; the H does not and is kept
>>> decompose_step(c, SwapToCX())
2-qubit circuit with 4 instructions:
├── H @ q[0]
├── CX @ q[0], q[1]
├── CX @ q[1], q[0]
└── CX @ q[0], q[1]

class DecompositionBasis[source]¶

Bases: ABC

Abstract base class for decomposition targets.

A basis decides which operations are terminal, that is kept as they are, and how to rewrite every other operation. decompose() rewrites each non-terminal operation with decompose() and repeats on the result until only terminal operations are left.

A subclass implements isterminal() and decompose().

Examples

>>> from mimiqcircuits import *
>>> # a basis of GateU and GateCZ: CX becomes H, CZ, H and the rest
>>> # follows the built-in decomposition
>>> class CZBasis(DecompositionBasis):
...     def isterminal(self, op):
...         return isinstance(op, (GateU, GateCZ))
...
...     def decompose(self, op, qubits, bits, zvars):
...         if isinstance(op, GateCX):
...             control, target = qubits
...             circ = Circuit()
...             circ.push(GateH(), target)
...             circ.push(GateCZ(), control, target)
...             circ.push(GateH(), target)
...             return circ
...         return CanonicalRewrite().decompose_step(op, qubits, bits, zvars)
>>> c = Circuit()
>>> c.push(GateCX(), 0, 1)
2-qubit circuit with 1 instruction:
└── CX @ q[0], q[1]

>>> # the H gates are not terminal, so they are decomposed in turn
>>> decompose(c, CZBasis())
2-qubit circuit with 3 instructions:
├── U((1/2)*pi, 0, pi, 0.0) @ q[1]
├── CZ @ q[0], q[1]
└── U((1/2)*pi, 0, pi, 0.0) @ q[1]

class DecompositionContext(nqubits=0, borrow=False, unitary_only=False, allocator=None, bit=None)[source]¶

Bases: object

State that decompose() hands to a basis and its rules.

The context goes next to the operation and its targets, through DecompositionBasis.decompose_ctx() and RewriteRule.decompose_step_ctx().

Parameters:

  • nqubits (int) – Width of the circuit being decomposed. Qubits 0, ..., nqubits - 1 that are not targets of the operation may be borrowed. 0 means the width is unknown, and nothing is borrowed.

  • borrow (bool) – Whether rules may borrow qubits outside the operation’s targets. A borrowed qubit can be in any state; the decomposition acts as the identity on it.

  • unitary_only (bool) – Set when the result must be unitary, as for the body of a wrapped GateDecl or of an IfStatement.

decompose() also hands out clean ancillas through the context when the basis has max_ancillas > 0. A rule that takes them brackets their use with AncillaAlloc and AncillaFree and returns them in |0>. With allow_measurement=True on the basis, the context also holds a classical bit, numbered after those of the circuit, that rules may measure an ancilla into.

Bases and rules that do not use the context inherit the default *_ctx methods, which drop it and call the method without it.

class CanonicalBasis(borrow=False, max_ancillas=0, allow_measurement=False)[source]¶

Bases: DecompositionBasis

Decomposition basis targeting GateU and GateCX.

Every gate is rewritten into GateU (an arbitrary single-qubit gate) and GateCX, with the built-in decomposition of each operation (CanonicalRewrite). The non-unitary primitives are kept as they are; isterminal() lists them. This is the default basis of decompose().

Parameters:

  • borrow (bool) – Let decompositions borrow qubits of the circuit that the operation does not act on. A borrowed qubit can be in any state; the decomposition leaves it as it found it.

  • max_ancillas (int) – Let decompositions add up to this many clean ancillas, numbered after the qubits of the circuit and marked with AncillaAlloc and AncillaFree. Ancillas freed by one operation are reused by the next.

  • allow_measurement (bool) – With max_ancillas, let decompositions undo steps by measuring an ancilla into one extra bit, numbered after the bits of the circuit. A circuit without bits is refused with a ValueError.

The three ancilla options are off by default, and only change how multi-controlled X gates are decomposed. Circuits whose width is unknown, such as a lone operation, get no ancillas.

Examples

>>> from mimiqcircuits import *
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateSWAP(), 0, 1)
2-qubit circuit with 2 instructions:
├── H @ q[0]
└── SWAP @ q[0:1]

>>> c.push(Measure(), 0, 0)
2-qubit, 1-bit circuit with 3 instructions:
├── H @ q[0]
├── SWAP @ q[0:1]
└── M @ q[0], c[0]

>>> # gates become GateU and GateCX; the measurement is kept
>>> decompose(c, CanonicalBasis())
2-qubit, 1-bit circuit with 5 instructions:
├── U((1/2)*pi, 0, pi, 0.0) @ q[0]
├── CX @ q[0], q[1]
├── CX @ q[1], q[0]
├── CX @ q[0], q[1]
└── M @ q[0], c[0]

class CliffordTBasis(sk_depth=None, rotations=None, borrow=False, max_ancillas=0, allow_measurement=False)[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the Clifford+T gate set.

Clifford+T is the standard universal gate set of error-corrected quantum computing. The terminal operations of this basis are those of StimBasis plus GateT and GateTDG, so the two bases always keep the same Clifford and stabilizer operations:

  • single-qubit Cliffords: GateID, GateX, GateY, GateZ, GateH, GateHXY, GateHYZ, GateS, GateSDG, GateSX, GateSXDG, GateSY, GateSYDG;

  • two-qubit Cliffords: GateCX, GateCY, GateCZ, GateSWAP, GateISWAP, GateISWAPDG, GateDCX, GateECR;

  • Pauli rotations by +-pi/2: GateRXX, GateRYY, GateRZZ, and RPauli with a non-identity Pauli string;

  • the non-Clifford GateT and GateTDG;

  • measurements, resets and measure-and-resets in the X, Y and Z bases, MeasureXX, MeasureYY, MeasureZZ and MeasurePauli;

  • Pauli noise: PauliX, PauliY, PauliZ, Depolarizing1, Depolarizing2 and PauliNoise;

  • barriers and annotations;

  • classical operations, which StimBasis does not keep;

  • an IfStatement whose body is terminal in this basis, with any condition. StimBasis only keeps a conditional GateX, GateY or GateZ on a single bit.

Non-terminal operations are rewritten by the first rule that matches, in this order:

  1. SpecialAngleRewrite: rotations by multiples of pi/4 to exact Clifford+T.

  2. GateECR to S, SX, CX and X, as in StimBasis, with no T gate.

  3. ToffoliToCliffordTRewrite: GateCCX to Clifford+T with 7 T gates.

  4. A GateU whose angles are all zero (a pure global phase) is dropped.

  5. ZYZRewrite: GateU to RZ*RY*RZ, and GateRX to GateRY between S and S†.

  6. ToZRotationRewrite: GateRY to GateRZ and Cliffords.

  7. The rotations rule (default GridSynthRewrite): remaining GateRZ to an approximate Clifford+T sequence.

  8. CanonicalRewrite: any other operation, toward GateU and GateCX. A GateRX, GateRY or GateRZ that reaches this point has a symbolic angle and raises DecompositionError.

The rotations rule only sees angles that step 1 could not decompose exactly. The body of an IfStatement goes through the same pipeline and stays conditional. No T-count optimization is performed on the result.

Parameters:

  • sk_depth (int | None) – Use SolovayKitaevRewrite with this recursion depth as the rotations rule.

  • rotations (RewriteRule) – Rule that synthesizes the remaining Z-rotations. The default GridSynthRewrite() approximates each rotation to operator-norm error 1e-10. The rule must match GateRZ with a numeric angle and emit only gates of this basis.

  • borrow (bool) – Let decompositions borrow qubits of the circuit that the operation does not act on. A borrowed qubit can be in any state; the decomposition leaves it as it found it.

  • max_ancillas (int) – Let decompositions add up to this many clean ancillas, numbered after the qubits of the circuit and marked with AncillaAlloc and AncillaFree. Ancillas freed by one operation are reused by the next.

  • allow_measurement (bool) – With max_ancillas, let decompositions undo steps by measuring an ancilla into one extra bit, numbered after the bits of the circuit. A circuit without bits is refused with a ValueError. With a clean ancilla, a GateCCX then costs 4 T instead of 7.

The three ancilla options are off by default, and only change how multi-controlled X gates are decomposed. Circuits whose width is unknown, such as a lone operation, get no ancillas.

Raises:

ValueError – If both sk_depth and rotations are given, or if rotations does not match GateRZ.

Decomposing an operation that no rule handles, such as a noise channel other than the Pauli ones above, raises a DecompositionError.

Examples

>>> from mimiqcircuits import *
>>> from symengine import pi
>>> c = Circuit()
>>> c.push(GateRZ(pi/4), 0)
1-qubit circuit with 1 instruction:
└── RZ((1/4)*pi) @ q[0]

>>> # a special angle is decomposed exactly
>>> decompose(c, CliffordTBasis())
1-qubit circuit with 1 instruction:
└── T @ q[0]

>>> # An arbitrary angle is approximated to 1e-10 by gridsynth
>>> c2 = Circuit()
>>> c2.push(GateRZ(0.123), 0)
1-qubit circuit with 1 instruction:
└── RZ(0.123) @ q[0]

>>> decomposed2 = decompose(c2, CliffordTBasis())

>>> # A looser error bound per rotation gives fewer T gates
>>> basis = CliffordTBasis(rotations=GridSynthRewrite(epsilon=1e-6))
>>> decomposed3 = decompose(c2, basis)
>>> def tcount(c):

Decomposition basis targeting the OpenQASM 2.0 gate library.

The terminal gates are the OpenQASM 2.0 built-ins and the gates of the qelib1.inc include file that have a direct MIMIQ counterpart, so a decomposed circuit can be written as OpenQASM 2.0 and read back by any parser that ships the standard qelib1.inc.

The terminal operations are:

  • the OpenQASM 2.0 built-ins GateU and GateCX;

  • the single-qubit gates of qelib1.inc: GateU3, GateU2, GateU1, GateID, GateX, GateY, GateZ, GateH, GateS, GateSDG, GateT, GateTDG, GateRX, GateRY and GateRZ;

  • the two-qubit gates of qelib1.inc: GateCY, GateCZ, GateCH, GateCRX, GateCRY, GateCRZ, GateSWAP, GateRXX and GateRZZ;

  • the three- and four-qubit gates of qelib1.inc: GateCCX, GateCSWAP and GateC3X;

  • Measure, Reset and Barrier, but not the X and Y variants of Measure and Reset;

  • annotations, such as AncillaAlloc, which the OpenQASM writer drops;

  • an IfStatement whose body is terminal;

  • a GateCall whose declaration holds only terminal operations.

Every other operation is decomposed through CanonicalRewrite. Operations that OpenQASM 2.0 cannot express and that have no decomposition into the gates above (noise channels, classical operations, Z-register operations, …) raise DecompositionError.

MeasureReset decomposes into Measure followed by Reset. This leaves the same state and bit as its canonical decomposition, a measurement and an X conditioned on its outcome, and unlike that conditional it can be written for a circuit of any number of bits. OpenQASM 2.0 has no loops, so WhileStatement raises DecompositionError.

Parameters:

  • max_ancillas (int) – Let decompositions add up to this many clean ancillas, numbered after the qubits of the circuit and marked with AncillaAlloc and AncillaFree. Ancillas freed by one operation are reused by the next.

  • allow_measurement (bool) – With max_ancillas, let decompositions undo steps by measuring an ancilla into one extra bit, numbered after the bits of the circuit. A circuit without bits is refused with a ValueError.

The three ancilla options are off by default, and only change how multi-controlled X gates are decomposed. Circuits whose width is unknown, such as a lone operation, get no ancillas.

class StimBasis[source]¶

Bases: DecompositionBasis

Decomposition basis targeting the gate set of the Stim stabilizer simulator.

Stim simulates stabilizer circuits: Clifford gates, Pauli measurements and resets, Pauli noise and quantum error correction annotations. Gates are rewritten toward that set by the first rule that matches, in this order:

  1. A GateU whose angles are all zero (a pure global phase) is dropped.

  2. ZYZRewrite: GateU to RZ*RY*RZ, and GateRX to GateRY between S and S†.

  3. SpecialAngleRewrite with only_cliffords=True: rotations by multiples of pi/2 to Clifford gates.

  4. GateECR to S, SX, CX and X, equal up to a global phase. Stim has no ECR instruction, and the canonical decomposition goes through non-Clifford RZX(+-pi/4).

  5. CanonicalRewrite: any other operation.

A GateRX, GateRY or GateRZ by any other angle is not a Clifford gate and raises DecompositionError; so does any non-Clifford gate that reduces to one, such as GateT. Use CliffordTBasis for such circuits.

The terminal operations are:

  • single-qubit Cliffords: GateID, GateX, GateY, GateZ, GateH, GateHXY, GateHYZ, GateS, GateSDG, GateSX, GateSXDG, GateSY and GateSYDG;

  • two-qubit Cliffords: GateCX, GateCY, GateCZ, GateSWAP, GateISWAP, GateISWAPDG and GateDCX;

  • Pauli rotations by +-pi/2: GateRXX, GateRYY, GateRZZ, and RPauli with a non-identity Pauli string. Angles are compared modulo 2*pi, since a rotation by 3*pi/2 equals one by -pi/2 up to a global phase. Other angles are decomposed;

  • measurements in any Pauli basis: Measure, MeasureX, MeasureY, MeasureXX, MeasureYY, MeasureZZ and MeasurePauli;

  • resets and measure-and-resets in the Z, X and Y bases: Reset, ResetX, ResetY, MeasureReset, MeasureResetX and MeasureResetY;

  • Pauli noise: PauliX, PauliY, PauliZ, Depolarizing1, Depolarizing2 and PauliNoise;

  • Barrier and annotations, including Detector, ObservableInclude and QubitCoordinates;

  • feedback: an IfStatement of GateX, GateY or GateZ conditioned on a single bit being 1.

The same Pauli conditioned on a bit being 0 becomes the Pauli followed by the Pauli conditioned on 1. Any other conditional operation has its body decomposed while staying conditional, and raises DecompositionError if that does not lead to conditional Paulis.

class SolovayKitaevRewrite(depth=3, simplify=True, net_max_depth=10, net_max_points=50000, net_min_dist=0.02)[source]¶

Bases: RewriteRule

Rewrite rule that approximates single-qubit gates with Clifford+T by Solovay-Kitaev.

The rule starts from the closest entry of a precomputed table (an epsilon-net) of short sequences of H, T, T†, S, S†, X, Y and Z, and refines it depth times with group commutators. Refinements lower the error on average, not at every step, and each multiplies the length of the sequence by about 5. The approximation holds up to a global phase. For Z-rotations, GridSynthRewrite gives much shorter sequences for the same error.

Parameters:

  • depth (int) – Number of refinements, at least 0 (default 3). With 0 the closest table entry is used as it is.

  • simplify (bool) – Cancel and merge adjacent gates of the result, such as T followed by T† or two S (default True).

  • net_max_depth (int) – Longest sequence in the table (default 10).

  • net_max_points (int) – Largest number of table entries (default 50000).

  • net_min_dist (float) – Smallest distance between two table entries (default 0.02).

Raises:

ValueError – If depth is negative.

Supported Operations

  • GateRZ(λ), GateRY(θ) and GateRX(θ)

  • GateU(θ, φ, λ, γ)

Only numeric parameters are matched; symbolic ones are not.

Examples

>>> from mimiqcircuits import *
>>> # one refinement of the closest table entry
>>> rule = SolovayKitaevRewrite(depth=1)
>>> circ = rule.decompose_step(GateRZ(0.123), [0], [], [])
>>> # the result only uses Clifford+T gates
>>> {type(inst.operation) for inst in circ} <= {GateH, GateT, GateTDG, GateS, GateSDG, GateX, GateY, GateZ}
True

Note

The table is built on first use, which takes a few seconds, and is then kept for later calls with the same net_* settings.

class GridSynthRewrite(epsilon=1e-10, seed=0)[source]¶

Bases: RewriteRule

Rewrite rule that approximates GateRZ with Clifford+T gates by gridsynth.

It implements the Ross–Selinger gridsynth algorithm. For GateRZ(λ) the rule emits a sequence of GateH, GateS, GateSDG, GateZ, GateT and GateX whose unitary V satisfies min_φ ‖RZ(λ) − e^{iφ}V‖ ≤ epsilon in operator norm. The approximation holds up to a global phase, which is dropped. The T-count is about 3·log₂(1/epsilon) and, except for rare failures of the integer factoring step, optimal among ancilla-free Clifford+T circuits with this error. Angles that are multiples of π/4 give their exact short decomposition.

The factoring step is randomized. For a fixed seed, the same angle and tolerance always give the same sequence. Results are cached per angle, since circuits often repeat the same rotation.

The synthesis runs in the compiled mimiqcircuits._core extension without holding the GIL, so several threads can synthesize in parallel.

Parameters:

  • epsilon (float) – Operator-norm tolerance, with 1e-100 <= epsilon < 1 (default 1e-10). A rotation takes a few milliseconds at 1e-10 and up to about a second at 1e-100.

  • seed (int) – Seed of the randomized factoring step, an integer in [0, 2**64) (default 0).

Raises:

  • ValueError – If epsilon or seed is out of range.

  • TypeError – If epsilon is not a real number or seed is not an integer.

Supported Operations

  • GateRZ(λ) with a numeric angle λ.

Symbolic angles are not matched. GateRX, GateRY and GateU must first be reduced to Z-rotations, for example with ZYZRewrite and ToZRotationRewrite. CliffordTBasis does this and uses this rule by default.

Examples

>>> from mimiqcircuits import *
>>> def tcount(c):
...     return sum(isinstance(i.operation, GateT) for i in c)
>>> # Approximate one rotation to the default tolerance 1e-10
>>> circ = GridSynthRewrite().decompose_step(GateRZ(0.123), [0], [], [])
>>> # A coarser tolerance gives fewer T gates
>>> coarse = GridSynthRewrite(epsilon=1e-4).decompose_step(GateRZ(0.123), [0], [], [])
>>> tcount(coarse) < tcount(circ)
True

References

N. J. Ross and P. Selinger, “Optimal ancilla-free Clifford+T approximation of z-rotations”, Quantum Inf. Comput. 16, 901 (2016), arXiv:1403.2975.

decompose(source, basis=None, wrap=False)[source]¶

Recursively decompose a circuit to a target basis.

Rewrites every operation of source that is not terminal in basis, and repeats on the result, until only terminal operations are left. The source is not modified.

Parameters:

  • source (Circuit | Instruction | Operation) – The circuit, instruction or operation to decompose. A bare operation is placed on qubits, bits and z-variables 0, 1, ....

  • basis (DecompositionBasis | RewriteRule | None) – The target basis. A RewriteRule is wrapped in a RuleBasis, so it is applied until it no longer matches. Defaults to CanonicalBasis.

  • wrap (bool) – If False (default), the result holds only terminal operations. If True, each non-terminal gate becomes a GateCall to a GateDecl holding its decomposition, and each other non-terminal operation (such as MeasureReset) a Block holding its decomposition, both wrapped again at every level. Gates that differ only in their parameters share one GateDecl. A gate whose decomposition measures an ancilla (allow_measurement=True) becomes a BlockCall to a shared BlockDecl. This keeps the structure of the original circuit visible.

Returns:

A new Circuit of terminal operations, plus GateCall and Block operations when wrap=True.

Raises:

  • TypeError – If source is not a circuit, instruction or operation.

  • DecompositionError – If basis cannot decompose an operation, for example a GateT in StimBasis.

Return type:

Circuit

Examples

>>> from mimiqcircuits import *
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> c.push(GateCCX(), 0, 1, 2)
3-qubit circuit with 2 instructions:
├── H @ q[0]
└── C₂X @ q[0:1], q[2]

>>> # the default basis leaves only GateU and GateCX
>>> sorted({type(inst.operation).__name__ for inst in decompose(c)})
['GateCX', 'GateU']

>>> # any other basis can be given
>>> sorted({type(inst.operation).__name__ for inst in decompose(c, CliffordTBasis())})
['GateCX', 'GateH', 'GateT', 'GateTDG']

>>> # with wrap=True each gate becomes a call to a declared gate,
>>> # so the two CH gates share one declaration
>>> c = Circuit()
>>> c.push(GateCH(), 0, 1)
2-qubit circuit with 1 instruction:
└── CH @ q[0], q[1]

>>> c.push(GateCH(), 1, 2)
3-qubit circuit with 2 instructions:
├── CH @ q[0], q[1]
└── CH @ q[1], q[2]

>>> decompose(c, wrap=True)
3-qubit circuit with 2 instructions:
├── mimiq_CH() @ q[0:1]
└── mimiq_CH() @ q[1:2]

class DecomposeIterator(source, basis, wrap=False, cache=None, nqubits=0, ctx=None)[source]¶

Bases: Iterator[Instruction]

Iterator over the instructions of a recursive decomposition.

Decomposes depth-first and yields each terminal instruction as soon as it is reached, in circuit order, so the decomposed circuit is never held in memory at once. Each non-terminal operation is decomposed only when the iteration reaches it. eachdecomposed() builds one with the default basis, and decompose() collects one into a circuit.

Parameters:

  • source (Circuit | Instruction | Operation) – The circuit, instruction or operation to decompose. A bare operation is placed on qubits, bits and z-variables 0, 1, ....

  • basis (DecompositionBasis) – The target basis. Unlike decompose(), a rewrite rule is not accepted here; wrap it in a RuleBasis.

  • wrap (bool) – If False (default), yield only terminal operations. If True, yield each non-terminal gate as a GateCall to a GateDecl holding its decomposition, and each other non-terminal operation (such as MeasureReset) as a Block holding its decomposition, in both cases wrapped again at every level. A gate whose decomposition measures an ancilla becomes a BlockCall to a BlockDecl.

  • cache (dict | None) – Dictionary that maps operations to the declaration built for them when wrap=True, keyed by the (symbolic) operation, the numbers of borrowed and clean qubits its body was offered, and whether it may measure. Pass the same dictionary to several iterators to share declarations between them. A new one is used by default.

  • nqubits (int) – Width of the circuit, which bounds the qubits a basis with borrow=True may borrow. Defaults to source.num_qubits() for a Circuit and to 0 (borrow nothing) for anything else, so the result never depends on the values of the target indices alone.

  • ctx (DecompositionContext | None) – The DecompositionContext to use instead of the one built from basis and nqubits.

Raises:

  • ValueError – If the basis borrows qubits and source contains Loss or Reload: losses act on qubits a borrowing decomposition relies on. Resolve them first, for example with lower_losses.

  • TypeError – If source is not a circuit, instruction or operation.

  • DecompositionError – While iterating, if the basis cannot decompose an operation.

Examples

>>> from mimiqcircuits import *
>>> c = Circuit()
>>> c.push(GateH(), 0)
1-qubit circuit with 1 instruction:
└── H @ q[0]

>>> # instructions are produced one at a time
>>> for inst in DecomposeIterator(c, CanonicalBasis()):
...     print(inst)
U((1/2)*pi, 0, pi, 0.0) @ q[0]
